# CSE-241: Data Structures

**Lectures:** 3 hours/cycle | **Credits:** 3

## 1. Introduction to Data Structures

- **Data Management Concepts**
    
- **Data Types:** Primitive and non-primitive
    
- **Types of Data Structures:** Linear and nonlinear
    
- **Operations on Data Structures**
    
- **Performance Analysis and Measurement:**
    
    - Time and space analysis of algorithms
        
    - Average, best, and worst-case analysis
        
    - Asymptotic notations ($O$, $\Omega$, $\Theta$)
## 2. Linear Data Structures

### Arrays

- Representations of different types of arrays
    
- Operations on arrays
    
- Pointer arrays
    
- Types and operations on matrices
    

### Linked Lists

- Types of linked lists
    
- Representation of linked lists
    
- Operations on linked lists
    
- Linked lists for representation of polynomials
    

### Stacks

- Definitions and concepts
    
- Memory representation of stacks
    
- Operations on stacks
    
- **Applications:**
    
    - Infix, prefix, and postfix expressions
        
    - Recursion and use of stacks in recursion
### Queues

- Definitions and representation
    
- Types of queues & Operations
    
- Circular Queue
    
- Priority Queue (and array representation)
    
- Double Ended Queue (Deque)
    
- Applications of Queues
## 3. Nonlinear Data Structures

### Trees

- Definitions and Concepts
    
- Representation of trees
    
- Tree traversal (In-order, Pre-order, Post-order)
    
- Threaded binary tree
    
- Conversion of General Trees to Binary Trees
    
- 2-trees and Balanced binary trees
    
- **Search Trees:** Binary Search Trees (BST), AVL trees, Red-black trees, M-way search trees, B-trees, and B+ trees
    
- Heaps
### Graphs

- Terminologies and representation of graphs
    
- Path matrix and strongly connected graph
    
- Operations on graphs
    
- **Traversals:** BFS (Breadth-First Search) and DFS (Depth-First Search)
    
- Topological sorting
    
- Minimum cost spanning trees (MST)
## 4. Sorting and Searching

- **Sorting Algorithms:** Bubble Sort, Selection Sort, Quick Sort, Merge Sort, Heap Sort, Radix Sort
    
- **Searching Algorithms:** Linear Search, Binary Search, Ternary Search, Jump Search, Interpolation Search, Exponential Search, Fibonacci Search
## 5. Hashing and File Structures

### Hashing

- The symbol table
    
- Hashing Functions
    
- Collision Resolution Techniques
### File Structure

- Concepts of fields, records, and files
    
- **File Organization:** Sequential, Indexed, and Relative/Random
    
- Indexing structure for index files
    
- Hashing for direct files
    
- Multi-key file organization and access methods
